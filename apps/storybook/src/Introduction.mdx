# Keycaps Design System

A plate, and a small number of solid objects seated on it. Keycaps is the owned
visual and interaction foundation for React projects under `jflamb.com`: brand
decisions live in framework-neutral CSS tokens, and accessible interaction
behavior comes from React Aria Components.

## Install

```sh
pnpm add @jflamb/keycaps-tokens @jflamb/keycaps-react react react-dom
```

```tsx
import "@jflamb/keycaps-tokens";
import "@jflamb/keycaps-react/styles.css";
import { Button } from "@jflamb/keycaps-react";
```

## Package boundaries

- `@jflamb/keycaps-tokens` has no framework dependency. It owns fonts, custom
  properties, semantic themes, base styles, the reduced-motion substitution, and
  the forced-colors mapping.
- `@jflamb/keycaps-react` owns the public component APIs and styling. React Aria
  Components remains an implementation detail wherever practical.
- This Storybook is the documentation site: narrative guidance, live examples,
  accessibility checks, and API reference stay together.

## Theme, motion, and forced colors

Keycaps follows the system theme unless the root element carries
`data-theme="light"` or `data-theme="dark"`, and the system motion preference
unless it carries `data-kc-motion="reduce"` or `"full"`. Existing jflamb
applications may continue storing a preference under `jflamb-theme`; the packages
write no cookies and no browser storage themselves.

The three controls in the toolbar above drive those same contracts on this site,
so what you switch here is what your app would switch.

## Status

Every component is `beta` until the automated checks and a documented manual
assistive-technology matrix are complete. Nothing here has reached `stable`, and
no page claims otherwise.

## Publishing

Storybook deploys to GitHub Pages only after the main CI workflow passes. npm
packages publish only from a GitHub Release whose `vX.Y.Z` tag exactly matches
both package versions.
