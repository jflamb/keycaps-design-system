# Font assets

Keycaps packages Latin WOFF2 assets for Fraunces and Nunito Sans so consuming applications do not make third-party runtime font requests.

- Fraunces: SIL Open Font License 1.1; see `LICENSE-FRAUNCES.txt`.
- Nunito Sans: SIL Open Font License 1.1; see `LICENSE-NUNITO-SANS.txt`.

These files were promoted from the existing jflamb application assets. Keep the license files with redistributed font binaries.
