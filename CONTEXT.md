# Keycaps

Keycaps is the owned visual and interaction language consumed by jflamb product and communication surfaces.

## Language

**Email theme**:
A flattened, versioned projection of canonical Keycaps tokens for constrained email renderers.
_Avoid_: Email CSS, copied palette, mail skin

**Email theme artifact**:
The generated JSON representation of an Email theme published with the token package and documentation site.
_Avoid_: Template, source tokens

**Email rendering**:
Disposable HTML and plain text produced by a consumer from semantic content and an Email theme.
_Avoid_: Email document, template source
